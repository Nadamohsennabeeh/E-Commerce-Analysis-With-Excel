# Beyond Sales Numbers: Hidden Insights | Excel

From raw data to clear insights.

This project analyzes sales data to uncover business patterns and understand what is behind the numbers.

## Key Indicators & Features

- **General KPIs:** Total Sales, Total Profit, and Total Quantity.
- **Product Analysis:** Top and Bottom Selling Products.
- **Category Analysis:** Sales by Category.
- **Payment Analysis:** Sales by Payment Mode.
- **City Analysis:** Top Sales by Cities.
- **Regional Analysis:** Total Sales by Region.
- **Customer Analysis:** Top Customers by Sales.
- **Profit Trends:** Total Profit by Month and Year.

## Tools Used

- Microsoft Excel
- Power Pivot
- PivotCharts
- Data Analysis
- Interactive Dashboard

## Project Duration

5 Days

## Project Goal

To turn raw sales data into meaningful insights, identify sales and profit patterns, and support better business decisions.
